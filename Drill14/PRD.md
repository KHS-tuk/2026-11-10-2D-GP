# Drill #14 새의 비행 애니메이션 PRD

## 목표

- `bird_animation.png`를 사용해 새 10마리의 비행 애니메이션을 구현한다.
- 새마다 초기 비행 방향을 다르게 설정한다.
- 새가 시간 기반으로 애니메이션과 수평 이동을 수행하고 화면 경계에서 방향을 반전한다.
- 기존 소년, 공, 잔디의 동작을 유지한다.

## 기능 요구사항

1. 게임 시작 시 새를 정확히 10마리 생성한다.
2. 스프라이트 시트의 14개 프레임을 순환 재생한다.
3. 애니메이션과 이동은 `game_framework.frame_time`을 사용한다.
4. 새의 이동 방향에 따라 스프라이트를 수평 반전한다.
5. 새가 화면 밖으로 나가지 않도록 위치를 보정한다.
6. 새 객체와 새 떼는 게임 월드의 초기화·업데이트·렌더링·종료 흐름에 연결한다.

## 개발 계획

1. 요구사항 및 스프라이트 구조 문서화
2. 새 객체의 기본 상태와 리소스 로드 구현
3. 스프라이트 프레임 절단 및 렌더링 구현
4. 시간 기반 애니메이션 구현
5. 새 10마리와 이동 관리 구현
6. 새마다 다른 초기 방향과 경계 반전 구현
7. 게임 모드 연동 및 종료 정리 구현
8. 실행·문법·동작 검증

## 수용 기준

- [ ] 화면에 새가 정확히 10마리 표시된다.
- [ ] 새마다 초기 방향이 번갈아 설정된다.
- [ ] 날갯짓이 끊김 없이 반복된다.
- [ ] 좌우 방향과 이미지 방향이 일치한다.
- [ ] 화면 경계에서 새가 방향을 바꾼다.
- [ ] `frame_time`이 0이면 위치와 프레임이 변하지 않는다.
- [ ] 기존 게임 기능에 회귀가 없다.

## 최종 커밋 로그

최종 구현 커밋에는 프레임 계산, 초기 방향 분산, 경계 보정, 기존 게임 루프 연동 논리를 기록한다.

## 구현 논리 기록

- 프레임은 `frame + frames_per_second * frame_time`으로 누적해 렌더링 호출 빈도에 영향을 받지 않게 한다.
- 새 생성 시 인덱스가 짝수면 오른쪽, 홀수면 왼쪽을 향하게 하여 처음부터 서로 다른 비행 방향을 만든다.
- 각 새는 자신의 방향으로 이동하며, 화면 경계에 닿으면 위치를 유효 범위로 보정한 뒤 방향을 반전한다.
- `BirdFlock`은 새를 10개만 생성하고 공통 `update()`와 `draw()` 흐름을 사용해 중복을 줄인다.
